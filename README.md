##  Why I Made This Website

I created this website as a way to introduce myself to the world and share the things I love.

I wanted to build something that represents my personality, interests and creativity rather than just having a normal profile page.

It's also an opportunity for me to learn web development, experiment with design and create something of my own.

##  What I Used

I built this website using:

- **HTML** – To create the structure and content of my website.
- **Tailwind CSS** – To style the website and create its design.
- **GitHub** – To store and share my project.

I chose a navy, off-white and electric-blue colour palette because I wanted a clean, modern and simple design.

##  Challenges I Faced

Building this website was a learning experience!

Some of the challenges I faced included:

- Understanding how HTML elements work together.
- Learning how to use Tailwind CSS classes.
- Choosing colours and designing a layout that looks clean.
- Organising different sections like About Me, Games I Love and Read Me.
- Figuring out how to display images correctly.

I didn't know everything from the beginning, so I learned by experimenting, making mistakes and improving my code.

##  What I Learned

Through this project, I got more comfortable with HTML and Tailwind CSS.

I also learned that building a website isn't just about writing code. It's about expressing ideas, making design decisions and solving problems along the way.
